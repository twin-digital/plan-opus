# Terms cannot be reviewed or noted on in the ruling session

The session-ruling TUI carries requirements and decisions but not terms, so a term reaches the
owner only through the raw sources or the PR description. Terms are owner-ratified input
changes — a coined word or changed definition is exactly what a sitting should surface — and
grinbox's current draft carries fifteen of them, several renaming published vocabulary. Present
terms in the session like requirements: visible with their definitions and scope, with the same
noting affordance, so a definition can be questioned or refined without leaving the sitting.
