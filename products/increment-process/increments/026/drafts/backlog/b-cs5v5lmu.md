# leave comments on an entry's text while ruling it

In the increment session's ruling mode (d-9g0poz7v), let the owner attach a comment to the selected entry -- a note asking for a wording change, not a ruling. The comment would have to reach whoever revises the text: as a PR review comment on the entry's line, or as something the draft carries for the next agent to pick up.

Named a reach feature on 2026-08-05, deliberately out of the first build. Ruling and landing are the flow that removes the round trip; commenting is what is left of the PR conversation once they do.
